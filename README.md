## ระบบตรวจสอบเอกสารนี้จัดทำขึ้นโดยรันอยู่บนโครงสร้าง Docker Container โดยดึงพลังการประมวลผลของ Intel(R) Arc(TM) Pro 140T GPU (8GB) จากเครื่องคอมพิวเตอร์ Windows Host ผ่านทาง host.docker.internal ไปยังระบบคิว Redis Queue และแสดงผลผ่านหน้าเว็บธีมสีกรมท่า (Navy Blue) และใช้ฟอนต์มาตรฐาน Sarabun

## 1. ข้อมูลการเข้าระบบสำหรับทดสอบ (Credentials)

ระบบได้รับการเตรียมข้อมูลผู้ใช้งานเริ่มต้นไว้เรียบร้อยแล้ว สามารถล็อกอินได้ทันทีผ่านเบราว์เซอร์ที่ลิงก์ http://localhost:8000 โดยใช้บัญชีดังนี้:

- บัญชีผู้ดูแลระบบ (Admin Role):
  อีเมล: admin@example.com
  รหัสผ่าน: password

- บัญชีผู้ใช้ทั่วไป (User Role):
  อีเมล: user@example.com
  รหัสผ่าน: password

## 2. โครงสร้างและการทำงานของระบบที่พัฒนา

2.1 การตั้งค่าดึง GPU VRAM ของ Intel Arc (Arc Pro 140T)
เนื่องจากตัวการ์ดจอ Intel Arc มีไดรเวอร์และส่วนสนับสนุนหลัก (Native Windows Support) ที่ดีที่สุดผ่านตัวโปรแกรม Ollama ที่รันบนระบบปฏิบัติการ Windows โดยตรง
ดังนั้น Docker จะเรียกใช้ Ollama บน Windows Host ที่ติดตั้งอยู่บนเครื่องผ่านลิงก์ http://host.docker.internal:11434
วิธีการทำงานนี้ทำให้ AI สามารถดึง VRAM ขนาด 8GB ของการ์ดจอ Intel Arc Pro 140T ในเครื่องมาใช้ประมวลผลข้อความภาษาไทยได้อย่างเต็มกำลังและรวดเร็วที่สุด โดยไม่ต้องเจอกับปัญหาไดรเวอร์ GPU ใน WSL2/Docker

สิ่งที่ต้องทำเพิ่มเติมบนเครื่องคอมพิวเตอร์หลัก:
1. ดาวน์โหลดและติดตั้ง Ollama บน Windows โดยตรงจากเว็บ ollama.com (หากเปิดรันไว้เรียบร้อยแล้ว ให้ปล่อยรันไว้)
2. เปิด PowerShell หรือ Command Prompt ของเครื่อง Windows แล้วสั่งดาวน์โหลดโมเดลภาษาไทยด้วยคำสั่ง: ollama pull qwen2.5:3b

2.2 การเปลี่ยนไปใช้งานกับการ์ดจอ NVIDIA (NVIDIA GPU Migration Guide)
หากต้องการย้ายระบบนี้ไปใช้งานบนเครื่องคอมพิวเตอร์ที่ติดตั้งการ์ดจอ NVIDIA สามารถเลือกดำเนินการได้ 2 รูปแบบดังนี้:

วิธีที่ 1: รัน Ollama บน Windows Host (แนะนำ - สะดวกและประสิทธิภาพสูงที่สุด)
ใช้วิธีเชื่อมต่อลักษณะเดียวกับการ์ดจอ Intel Arc โดยที่ฝั่ง Docker ไม่จำเป็นต้องติดตั้งไดรเวอร์หรือตั้งค่าการ์ดจอใดๆ เพิ่มเติม:
1. ดาวน์โหลดและติดตั้ง Ollama สำหรับ Windows จากเว็บ ollama.com ตัวโปรแกรมจะตรวจพบการ์ดจอ NVIDIA และเปิดใช้งาน VRAM โดยอัตโนมัติ
2. เปิด Command Prompt หรือ PowerShell บนเครื่องโฮสต์และพิมพ์คำสั่งดึงโมเดล: ollama pull qwen2.5:3b
3. รัน Docker Container ของโปรเจกต์นี้ตามปกติ ระบบจะติดต่อการ์ดจอผ่านช่องทาง host.docker.internal เพื่อส่งงานให้การ์ดจอประมวลผลได้ทันที

วิธีที่ 2: รัน Ollama ภายในตู้ Docker (Full Containerization)
หากต้องการให้ทุกอย่างรวมอยู่ใน Docker โดยไม่อยากติดตั้งแอปพลิเคชันเพิ่มใน Windows:
1. เตรียมสภาพแวดล้อมที่เครื่อง Host:
   - ติดตั้งไดรเวอร์การ์ดจอ NVIDIA และตรวจสอบความเรียบร้อย
   - บน Windows ให้ใช้ PowerShell รันคำสั่งอัปเดต WSL2: wsl --update
   - สำหรับฝั่ง Linux Host ต้องติดตั้ง NVIDIA Container Toolkit เพื่อส่งการ์ดจอเข้าตู้คอนเทนเนอร์
2. แก้ไขไฟล์คอนฟิกในโปรเจกต์:
   - ในไฟล์ docker-compose.yml ให้เขียนเปิดใช้งาน service ollama กลับมา โดยระบุการตั้งค่า deploy.resources.reservations.devices สำหรับ nvidia driver และทำการปรับเปลี่ยนให้ตู้ queue-worker ชี้ไปที่คอนเทนเนอร์ ollama แทน
   - ในไฟล์ .env และ .env.example ให้เปลี่ยน URL ไปหา Container แทน Host: OLLAMA_URL=http://ollama:11434
3. รันตู้ Docker ขึ้นมาใหม่ด้วยคำสั่ง: docker-compose down ตามด้วย docker-compose up -d --remove-orphans

2.3 ระบบความปลอดภัยและการจัดการไฟล์ (Private Storage Security)
- ไฟล์ PDF ที่อัพโหลดจะถูกเก็บไว้ที่ storage/app/private/documents ซึ่งแยกออกจากโฟลเดอร์สาธารณะ (Public Directory) ของเว็บ
- การดาวน์โหลดหรือดูเอกสารผ่าน URL จะถูกคัดกรองโดย Controller เพื่อตรวจสอบความถูกต้องของสิทธิ์เจ้าของเอกสารหรือสิทธิ์ผู้ดูแลระบบเท่านั้น หากไม่ได้รับอนุญาต ระบบจะตอบกลับด้วยข้อความแจ้งเตือน 403 Forbidden ป้องกันการเดาสุ่มดาวน์โหลดไฟล์ข้อมูล

## 3. ขั้นตอนการใช้งานระบบ (Manual Verification Guide)

ขั้นตอนที่ 1: เข้าใช้งานในฐานะผู้ใช้ทั่วไป (User)
1. เปิดเบราว์เซอร์ไปที่ลิงก์ http://localhost:8000 ระบบจะทำหน้าที่นำทางไปยังหน้าเข้าสู่ระบบที่ปลอดภัยโดยอัตโนมัติที่หน้า /login
2. ทำการล็อกอินด้วยอีเมล user@example.com และรหัสผ่าน password
3. การส่งตรวจสอบเอกสาร:
   - กรอกชื่อรายการเอกสาร (เช่น รายงานการประชุมคณะกรรมการ ครั้งที่ 2/2569)
   - ระบุคำหรือเงื่อนไขที่ต้องการให้ AI ตรวจสอบ (เช่น ตรวจหาคำว่า อนุมัติงบประมาณจัดซื้อเครื่องเขียน)
   - เลือกไฟล์เอกสาร PDF (ขนาดไม่เกิน 10MB)
   - กดปุ่ม ส่งตรวจสอบเอกสาร
4. ระบบจะส่งงานเข้าคิวของ Redis และส่งต่อไปประมวลผลผ่านตัว Ollama บนเครื่องของท่านแบบเบื้องหลัง
5. เมื่อเสร็จสิ้น สามารถคลิกปุ่ม ดูผล เพื่อดูสรุปความเห็นของ AI หรือคลิกปุ่ม พิมพ์รายงาน เพื่อบันทึกเป็น PDF หรือ ดาวน์โหลดรายงานในรูปแบบไฟล์ CSV ได้

ขั้นตอนที่ 2: เข้าใช้งานในฐานะผู้ดูแลระบบ (Admin)
1. ล็อกอินเข้าสู่ระบบด้วยอีเมล admin@example.com และรหัสผ่าน password
2. หน้าแผงควบคุมระบบ (Admin Dashboard) จะแสดงผลสถิติภาพรวมทั้งหมดของระบบ และตารางข้อมูลเอกสารจากผู้ใช้ทุกคน สามารถค้นหาและกรองสถานะข้อมูลได้ทันที
3. สามารถคลิกปุ่ม ดูรายละเอียด เพื่อดึงข้อมูลวิเคราะห์เชิงลึกของแต่ละเอกสารจาก AI ขึ้นมาแสดงผลบนกล่องข้อความป๊อปอัปได้อย่างรวดเร็ว
4. สามารถเข้าหน้าจอ จัดการผู้ใช้ เพื่อเพิ่มข้อมูลผู้ใช้ใหม่ แก้ไขรหัสผ่าน/บทบาท หรือลบบัญชีสมาชิกในระบบได้ทันที

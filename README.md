## การติดตั้งระบบ สำหรับ เครื่องที่ไม่มี การ์ดจอ Nvidia บน Windows 

## ภายใน Docker

    1. Docker compose up -d

## เครื่อง Host ติดตั้ง Ollama
 
    1.ดาวน์โหลดและติดตั้งโปรแกรม Ollama สำหรับ Windows จาก ollama.com (หากรันอยู่แล้ว ให้ตรวจสอบว่าเปิดใช้งานอยู่ตรง system tray ด้านขวาล่างของจอ)
    
    2.เปิด Command Prompt หรือ PowerShell ในเครื่อง Windows ของท่าน แล้วสั่งดาวน์โหลดโมเดลภาษาไทยด้วยคำสั่งนี้: ollama pull qwen2.5:3b

## การใช้งาน
### ขั้นตอนที่ 1: เข้าใช้งานในฐานะผู้ใช้ทั่วไป (User)

    1.เปิดเบราว์เซอร์ไปที่ http://localhost:8000 ระบบจะทำหน้าทีนำทางไปยังหน้าเข้าสู่ระบบโดยอัตโนมัติที่ /login

    2.ล็อกอินด้วย user@example.com / password

    3.ส่งตรวจสอบ:

        กรอกชื่อรายการเอกสาร (เช่น "รายงานการประชุมครั้งที่ 2/2569")

        ระบุคำ/เงื่อนไขที่ต้องการตรวจสอบ (เช่น "ตรวจหาการอนุมัติจัดหาเครื่องคอมพิวเตอร์")

        ลากหรือเลือกไฟล์เอกสาร PDF (ไม่เกิน 10MB)

        กดปุ่ม "ส่งตรวจสอบเอกสาร"

    4.ระบบจะส่งงานเข้าคิวของ Redis และประมวลผลผ่านตัว Ollama บนเครื่อง Windows ของท่าน

    5.สามารถคลิก "ดูผล" เพื่อดูรายละเอียดที่ AI สรุปและวิเคราะห์ หรือคลิก "พิมพ์รายงาน" หรือดาวน์โหลด "รายงาน CSV" ได้

### ขั้นตอนที่ 2: เข้าใช้งานในฐานะผู้ดูแลระบบ (Admin)
    
    1.ล็อกอินด้วย admin@example.com / password
    
    2.แผงควบคุมระบบ (Admin Dashboard): แสดงสถิติและตารางข้อมูลเอกสารจากผู้ใช้ทุกคน ค้นหาและคัดกรองข้อมูลได้ง่าย และกดคลิกดูรายละเอียดผ่าน Ajax Modal
    
    3.เข้าหน้าจอ "จัดการผู้ใช้" เพื่อทำธุรกรรม CRUD (เพิ่ม, แก้ไข, ลบ) บัญชีสมาชิกได้
